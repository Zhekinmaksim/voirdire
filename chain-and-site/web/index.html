Voirdire

A vendor says its agent runs on a particular model. You pay for that model. Voirdire asks whether the behaviour you can observe is consistent with the claim, and puts the vendor's bond behind the answer.

This is not proof of model identity. A black box does not permit that proof. What is on offer is behavioural testimony against a declared claim, and what gives it force is the bond, not the verdict.

What the battery can and cannot separate

Every pair of model families the probes run against, and how far apart they sit relative to how far a family sits from itself. Brightness carries magnitude. A pair that falls below the floor turns spectral, because that is what an interference film does when two surfaces return the same colour from every angle you have.

    How a round runs

    The order is the mechanism. Commit strictly before sending, send strictly before revealing. Get that wrong and the vendor sees the probe set first, routes it to the expensive model, and the round measures nothing.

    1. The vendor registers a claim: agent, model family, a dated version, a validity window. It stands only while a bond stands behind it.
    2. A challenger picks probes and writes their hash on chain. The hash covers a nonce, because the corpus is public and a commitment over known text alone is brute-forceable.
    3. The probes go to the agent as ordinary traffic, at a moment the challenger chooses. Nothing in them reads as an audit.
    4. The challenger reveals the transcripts. Consensus reads them one probe class at a time and returns match, mismatch or unclear, naming the fragment it relied on.
    5. The verdict is arithmetic over those readings, never a second opinion. A divergence pays only after two referee rounds: is it visible in the submitted text, and do these transcripts belong to this agent and this declared version.
    6. Every revealed probe is spent. From that block the vendor can cache it, so it leaves the active set.

    The probe corpus

    Each probe is an ordinary task with a discriminating element inside it. A probe that reads as an audit gets routed to the expensive model and measures nothing. Refusal-shape probes stay in the benign band: what is measured is where the boundary sits, never what lies behind it.

    Verdicts

    Three, fixed when a claim is registered.

    CONSISTENTThe profile fits the claimed model on two or more classes, with none pointing the other way.
    INCONSISTENTIt does not fit, with the diverging classes named. A single mismatch never qualifies, because a single mismatch is what temperature noise produces.
    INCONCLUSIVEToo few classes read, the evidence was unreadable, or the classes pointed opposite ways. This is not a pass. A claim reads unexamined until it has survived its required rounds, and there is no path from silence to a clean record.
